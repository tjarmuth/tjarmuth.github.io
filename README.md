# Portfolio Tristan Jarmuth

Statische Seite aus HTML, CSS und JavaScript, ohne Build-Schritt.

## Dateien
- `index.html`: Startseite
- `impressum.html`, `datenschutz.html`: Unterseiten (Platzhalter in eckigen Klammern ausfüllen)
- `css/style.css`: alle Styles (Farben und Schriften als Variablen am Anfang)
- `js/main.js`: Sprachwahl, mobiles Menü, geschützter E-Mail-Link
- `images/`: Bilder
- `.nojekyll`: sorgt dafür, dass GitHub Pages die Dateien unverändert ausliefert

## Veröffentlichen mit GitHub Pages
1. Neues öffentliches Repository anlegen (für `https://<benutzername>.github.io` heißt es `<benutzername>.github.io`).
2. Den Inhalt dieses Ordners ins Repository hochladen, `index.html` muss im Hauptverzeichnis liegen.
3. Im Repository unter Settings > Pages als Quelle "Deploy from a branch" mit Branch `main` und Ordner `/ (root)` wählen.
4. Nach kurzer Zeit ist die Seite unter der angezeigten Adresse erreichbar.

Hinweis: Dateinamen sind auf GitHub Pages groß- und kleinschreibungsabhängig.
